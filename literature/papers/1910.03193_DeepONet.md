# DeepONet: Learning nonlinear operators for identifying differential equations based on the universal approximation theorem of operators (2019)

- **Authors / venue:** L. Lu, P. Jin, G. E. Karniadakis (Brown). Nature Machine Intelligence 3, 218–229 (2021).
- **Links:** https://arxiv.org/abs/1910.03193 · code in DeepXDE https://github.com/lululxvi/deepxde
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators

## Summary
Operator G: u ↦ G(u)(y) approximated as the dot product of a **branch net** (encodes the input function sampled at fixed sensors) and a **trunk net** (encodes the query coordinate y): `G(u)(y) ≈ Σ_k b_k(u) t_k(y)`. The paper covers stacked and unstacked variants. Its original test cases include **dynamic systems driven by an input signal u(t)** (ODE operators) as well as PDEs.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | **Mesh-agnostic**: trunk queries any coordinate; the branch needs fixed sensors (e.g. our 21334 cells or a POD projection) |
| Exogenous conditioning | **Native** — the original paper's canonical task is learning the response to a forcing signal u(t). In FlameBench: branch input = [last n_past snapshots (or their POD coefficients), phi history, phi(t+1)]; trunk = cell coordinates |
| Latent reduction | The p branch/trunk products form a learned linear basis (the trunk outputs are "learned POD modes"). The POD-DeepONet variant (Lu et al. 2022) fixes the trunk to POD modes |
| Prediction target | Absolute field at query points |
| Rollout & stability | Not addressed (one-shot operator); used autoregressively or time-conditioned in later work |
| Demonstrated scale | Small (1D/ODE) in the original paper |
| Datasets / physics | Antiderivative, nonlinear ODEs, gravity pendulum with forcing, diffusion-reaction PDE |
| Code + license | DeepXDE — LICENSE_TBD |
| Integration effort | **Low.** A branch MLP on flattened history (or POD coefficients) and a trunk MLP on `xyz`; loss per cell |

## Relevance to FlameBench
**Must-include baseline.** (1) In REALM it was the **best model on every irregular-mesh reacting case**, while GNNs and spectral models degraded. (2) Its problem statement — the response of a system to an input signal — is the FlameBench problem. With a fixed-POD trunk it becomes a close cousin of our `pod-*` models, which makes for a clean ablation (learned trunk vs POD trunk). (3) Very cheap at 21k cells.
