# Learning Mesh-Based Simulation with Graph Networks — MeshGraphNets (2020)

- **Authors / venue:** T. Pfaff, M. Fortunato, A. Sanchez-Gonzalez, P. Battaglia (DeepMind). ICLR 2021.
- **Links:** https://arxiv.org/abs/2010.03409 · code https://github.com/google-deepmind/deepmind-research/tree/master/meshgraphnets (TF1). Many PyTorch ports exist (e.g. NVIDIA PhysicsNeMo)
- **Source read:** tex (arXiv e-print)
- **Thread:** 3 GNNs

## Summary
Encode–process–decode GNN on the simulation mesh itself. Mesh nodes become graph nodes and mesh edges become bidirectional edges, with relative positions as edge features for translation invariance. L=15 residual message-passing blocks with 128-d latents. The decoder outputs a time derivative, integrated with forward Euler (**residual update `q^{t+1} = q^t + p`**). Optional adaptive remeshing.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | **Native unstructured mesh** (triangles/tets); edges from mesh connectivity (we would need cell adjacency or a kNN/radius graph from `xyz.npy`) |
| Exogenous conditioning | None built in; phi can go in as a **global node feature** (broadcast to all nodes) or a global graph attribute in GraphNet style |
| Latent reduction | None (per-node latents) |
| Prediction target | **Residual / derivative**, like our sequence models |
| Rollout & stability | **Training noise injection** (GNS-style): Gaussian noise on the input state, with targets corrected so the model learns to undo it. Noise scale tuned around the 1-step error (CylinderFlow momentum 2e-2; Airfoil momentum 1e1, density 1e-2). Stable for hundreds of steps |
| Demonstrated scale | CylinderFlow ~1.9k nodes x 600 steps; Airfoil 5,233 nodes x 600 steps; 1000 training trajectories |
| Datasets / physics | Incompressible cylinder flow, compressible airfoil, cloth, hyperelastic plate |
| Code + license | deepmind-research — LICENSE_TBD |
| Integration effort | **Medium.** Needs graph construction; 15 MP steps over 21k nodes is fine on GPU. PyTorch Geometric has all the pieces |

## Relevance to FlameBench
**Must-include GNN baseline** — the reference mesh-based learned simulator. Its data regime is very different from ours (1000 trajectories vs our 2 long sine-sweep runs), and REALM found MGN **over-smooths and becomes unstable on anisotropic, multi-resolution combustion meshes**. That is a useful, publishable negative result to confirm or refute. The noise-injection recipe is transferable to **all** our AR models (see also MP-PDE pushforward).
