# AROMA: Preserving Spatial Structure for Latent PDE Modeling with Local Neural Fields (2024)

- **Authors / venue:** L. Serrano, T. X. Wang, E. Le Naour, J.-N. Vittaut, P. Gallinari (Sorbonne / ISIR). NeurIPS 2024.
- **Links:** https://arxiv.org/abs/2406.02176 · code https://github.com/LouisSerrano/aroma
- **Source read:** tex (arXiv e-print)
- **Thread:** 1 latent ROM + sequence / 5 probabilistic

## Summary
A latent reduced-order model for any sampling. **Encoder:** Fourier-feature coordinates plus linear value embeddings, cross-attended onto M learnable query tokens (first geometry only, then values), then a channel bottleneck, trained as a **VAE**. **Decoder:** self-attention on the tokens, then cross-attention from query coordinates, then a local INR, so it can be queried anywhere. **Dynamics:** a DiT-style **conditional diffusion transformer** that refines `Z^{t+dt}` given `Z^t` (v-prediction DDPM). Training has two stages: autoencoder first, then the frozen-latent dynamics.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Grid, irregular mesh or point set (cross-attention encoder) |
| Exogenous conditioning | None, but the DiT backbone already has a conditioning pathway (adaLN from the diffusion step). phi(t+1) can be added to that embedding — low effort |
| Latent reduction | **Learned token latent (VAE)**, M tokens x small h. Spatially interpretable tokens (local receptive fields) |
| Prediction target | Next latent `Z^{t+dt}` (diffusion-refined) |
| Rollout & stability | Latent AR rollout; the diffusion refiner is reported to give "greater stability and longer rollouts than MSE training"; also yields uncertainty estimates |
| Demonstrated scale | Small: 64x64 NS, spherical shallow water, MeshGraphNets CylinderFlow/AirfoilFlow (~2k-5k nodes). 256 training trajectories x 40 steps |
| Datasets / physics | Burgers, NS (1e-3, 1e-4, 1e-5), shallow water, cylinder/airfoil flow; KS reported as a failure case |

| Integration effort | **Medium-high.** Two-stage training and a diffusion sampler at inference (several denoising steps per time step) |

## Relevance to FlameBench
A strong candidate for the **"learned-latent" family** on unstructured meshes. It is the natural nonlinear successor of `pod-transformer`/`ae-transformer`, with a mesh-agnostic encoder and optional probabilistic dynamics. It is also the only model here that gives uncertainty for free. Risk: untested beyond ~5k nodes; at 21k cells the encoder cross-attention (N x M) is still cheap. Pair it with UPT in the benchmark: both are "encode mesh → latent tokens → transformer propagator" (UPT deterministic, AROMA diffusion).
