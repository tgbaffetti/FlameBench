# Geometry-Informed Neural Operator for Large-Scale 3D PDEs — GINO (2023)

- **Authors / venue:** Z. Li, N. Kovachki, C. Choy, B. Li, J. Kossaifi, S. P. Otta, M. A. Nabian, M. Stadler, C. Hundt, K. Azizzadenesheli, A. Anandkumar (NVIDIA / Caltech). NeurIPS 2023.
- **Links:** https://arxiv.org/abs/2309.00583 · code in the `neuraloperator` library (https://github.com/neuraloperator/neuraloperator, `GINO` model)
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators

## Summary
A **graph neural operator (GNO) encoder** integrates the irregular point cloud onto a **regular latent grid** (radius-ball kernel integral with Riemann weights and Fourier-feature kernels). An **FNO** runs on that grid, and a **GNO decoder** queries the output at arbitrary mesh points. It is discretization-convergent. Tested on steady 3D car aerodynamics (ShapeNet Car, Ahmed body at Re up to ~7e6).

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | **Native unstructured mesh / point cloud** (plus an optional SDF on the latent grid). The learned GNO replaces hand-made interpolation |
| Exogenous conditioning | **Built in for a scalar:** the inlet velocity is Fourier-feature embedded → MLP → scale/shift of **adaptive instance normalisation** in every FNO block. This is exactly the mechanism to reuse for phi(t+1) |
| Latent reduction | None in the POD sense; latent = regular grid |
| Prediction target | Absolute field (steady) |
| Rollout & stability | Steady problems only in the paper; UPT later used GINO as a transient baseline (next-step, with spatial-spectral conditioning) |
| Demonstrated scale | ~100k+ surface/volume points, 3D; latent grids up to 64^3 |
| Datasets / physics | ShapeNet Car (889 shapes), Ahmed body (with variable inlet velocity 10-70 m/s) |
| Code + license | neuraloperator library — LICENSE_TBD |
| Integration effort | **Medium.** Needs radius-graph neighbour search (the library ships it) and a latent grid size choice for our 2D/axisymmetric domain |

## Relevance to FlameBench
**The principled fix for our broken `fno3d` path** (ISSUES #4: `grid_shape [256,64]` ≠ 21334 cells). Instead of pre-interpolating snapshots onto a grid, GINO learns the mesh→grid→mesh maps, and the FNO core stays as is. It also shows how to inject a scalar (AdaIN with Fourier features). Include it as the **"FNO family on unstructured mesh"** representative, alongside or instead of Geo-FNO.
