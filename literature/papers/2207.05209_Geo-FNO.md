## Summary
It learns a (near-)diffeomorphic deformation from the irregular physical domain to a uniform latent torus, where an FNO applies the FFT. The first and last layers use a "geometric Fourier transform", evaluated directly on the irregular points. Inputs can be point clouds, meshes or design parameters.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Irregular mesh / point cloud, via a learned deformation. Works best when the domain is topologically close to a box (structured-like C-meshes, e.g. airfoil 221x51) |
| Exogenous conditioning | None; would need concatenation of phi as constant channels or FiLM/AdaIN (as in GINO) |
| Latent reduction | None; latent uniform grid |
| Prediction target | Absolute field |
| Rollout & stability | Mostly steady / single-map tasks; plasticity predicts 20 future steps jointly |
| Demonstrated scale | ~1k-30k points (elasticity 972 points, airfoil 221x51, pipe 129x129) |
| Datasets / physics | Hyper-elasticity, plasticity, advection on sphere, airfoil Euler, pipe NS |

## Relevance to FlameBench
A **possible fix for `fno3d` if our 21334-cell mesh is essentially a deformed structured mesh** (check `xyz.npy`: if cells come from a block-structured mesh, a fixed (non-learned) index map to a grid may even work directly). Transolver reports that Geo-FNO "degenerates seriously" on real unstructured design tasks (ShapeNet Car, AirfRANS). **GINO is the more robust choice for a truly unstructured mesh.** Keep Geo-FNO as a cheap alternative or ablation.
