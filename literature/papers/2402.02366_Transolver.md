# Transolver: A Fast Transformer Solver for PDEs on General Geometries (2024)

- **Authors / venue:** H. Wu, H. Luo, H. Wang, J. Wang, M. Long (Tsinghua, THUML). ICML 2024 (spotlight).
- **Links:** https://arxiv.org/abs/2402.02366 · code https://github.com/thuml/Transolver
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators

## Summary
A transformer for PDEs on arbitrary meshes. "Physics-Attention" softly assigns each of the N mesh points to M learnable *slices* (softmax over a linear projection of point features), aggregates each slice into one token, runs full attention among the M tokens (M ~ 32-64), and broadcasts back to points with the same weights. Cost is O(NMC), linear in the number of cells.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | **Native unstructured mesh / point cloud.** Input embedding = Linear(concat(coords, fields)). `Project()` is a linear layer on unstructured meshes (a 3x3 conv on structured ones) |
| Exogenous conditioning | None built in. The natural hook for phi: broadcast `[phi_{t-n+1..t}, phi_{t+1}]` as extra per-point input channels, or add them as an extra global token. Both are trivial |
| Latent reduction | No explicit reduction, but the M slice tokens act as a learned, data-adaptive, nonlinear "POD-like" basis |
| Prediction target | Absolute field in the paper; residual is a one-line change |
| Rollout & stability | Time-dependent NS benchmark: 10 past steps in, 10 future out, autoregressive. No special stability trick |
| Demonstrated scale | Up to ~32k points (ShapeNet Car 32,186; AirfRANS 32,000). **This is the same order as our 21,334 cells** |
| Datasets / physics | Elasticity, Plasticity, Airfoil, Pipe, NS (64x64), Darcy, ShapeNet Car, AirfRANS |
| Code + license | thuml/Transolver — LICENSE_TBD |
| Integration effort | **Low.** Input tokens = 21334 cells x (n_past*Nf + coords + phi channels); output Nf per cell. Configs in the paper: 8 layers, 8 heads, C=128-256, M=32-64, AdamW lr 1e-3, relative-L2 loss |

## Relevance to FlameBench
**Priority candidate.** It is the strongest general-purpose mesh-native transformer that works at our scale with no interpolation, so it replaces the broken `fno3d`/`unet` path for "full-field" models. REALM found it degrades on shocks and thin reaction zones and over-smooths on irregular cases, so it is a fair, strong-but-beatable baseline. The slice visualisations could be interesting for interpreting flame-front regions.
