# PDE-Refiner: Achieving Accurate Long Rollouts with Neural PDE Solvers (2023)

- **Authors / venue:** P. Lippe, B. S. Veeling, P. Perdikaris, R. E. Turner, J. Brandstetter (Microsoft Research AI4Science). NeurIPS 2023.
- **Links:** https://arxiv.org/abs/2308.05732 · code in https://github.com/microsoft/pdearena
- **Source read:** tex (arXiv e-print)
- **Thread:** 6 rollout stability / 5 probabilistic

## Summary
A large-scale analysis of rollout strategies shows that one-step MSE training **neglects low-amplitude (usually high-frequency) spatial components**, and that this is the main cause of long-rollout divergence. PDE-Refiner fixes it with a few (K ≈ 1-8) **denoising refinement steps**: the same network takes the previous state, the refinement index k and its current prediction plus noise of decreasing variance, and refines the prediction so that every frequency band gets equal attention. It is a diffusion model with very few steps, and it also yields uncertainty estimates.
