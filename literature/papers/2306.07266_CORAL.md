# Operator Learning with Neural Fields: Tackling PDEs on General Geometries — CORAL (2023)

- **Authors / venue:** L. Serrano, L. Le Boudec, A. Kassaï Koupaï, T. X. Wang, Y. Yin, J.-N. Vittaut, P. Gallinari (Sorbonne / ISIR). NeurIPS 2023.
- **Links:** https://arxiv.org/abs/2306.07266 · code https://github.com/LouisSerrano/coral
- **Source read:** tex (arXiv e-print)
- **Thread:** 1 latent ROM + sequence / 2 operators

## Summary
Encode–process–decode with **implicit neural representations (INRs)**. Each field is a modulated SIREN whose shift-modulations come from a small code z through a linear hypernetwork. Encoding is **auto-decoding**: a few (3) gradient steps on z, meta-learned with second-order CAVIA. The processor is an MLP (for initial-value problems) or a **Neural ODE in code space** (for dynamics). Training has two stages: INRs first, then the processor on frozen codes.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Any point sampling — grids, irregular meshes, sparse subsamples; train and test grids can differ |
| Exogenous conditioning | None; phi would enter the Neural ODE vector field `zeta(z, phi(t))` — natural for a continuous-time forcing |
| Latent reduction | Global latent code (vector, d_z ~ 128) — a nonlinear, mesh-free analogue of POD coefficients |
| Prediction target | Latent code trajectory via ODE integration |
| Rollout & stability | Latent AR / ODE rollout; temporal-extrapolation test (In-t vs Out-t) |
| Demonstrated scale | 64x64 NS subsampled, spherical shallow water, Geo-FNO airfoil/pipe/elasticity; 256 training trajectories |
| Datasets / physics | NS, shallow water, NACA, pipe, elasticity, inverse design |
| Code + license | LouisSerrano/coral — LICENSE_TBD |
| Integration effort | Medium. Test-time optimisation for encoding makes inference slower and the pipeline unusual for `compute_loss` (two stages) |

## Relevance to FlameBench
Methodologically interesting as the **"nonlinear POD on any mesh"** baseline, and a Neural ODE with forcing fits a phi(t)-driven flame well. The authors' own follow-up (AROMA) beats it in most settings and is easier to condition, so **prefer AROMA**. Keep CORAL for the related-work section, or as an optional baseline if we want a global-vector latent comparable to our POD rank-10.
