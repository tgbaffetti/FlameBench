# Benchmarking Autoregressive Conditional Diffusion Models for Turbulent Flow Simulation — ACDM (2023)

- **Authors / venue:** G. Kohl, L.-W. Chen, N. Thuerey (TU Munich). Neural Networks (2026); earlier ICML 2023 workshop / arXiv 2023.
- **Links:** https://arxiv.org/abs/2309.01745 · code+data+models https://github.com/tum-pbs/autoreg-pde-diffusion
- **Source read:** tex (arXiv e-print)
- **Thread:** 5 probabilistic / 6 rollout stability

## Summary
An **autoregressive conditional DDPM**: a U-Net denoiser generates s^t conditioned on k=2 previous states, rolled out autoregressively (20–100 diffusion steps per time step). It is benchmarked against the **same U-Net backbone** trained (a) one-step MSE, (b) **unrolled** (m=8, full backprop), (c) with **training noise**, plus dilated ResNet, FNO, PDE-Refiner and **latent-space transformers**. Three 2D cases with out-of-distribution test parameters: incompressible wake, transonic cylinder (shocks), isotropic turbulence.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Regular grid (U-Net); unstructured data would need GINO/graph backbones |
| Exogenous conditioning | Simulation parameters (Re, Mach) are included as constant input channels; no time-varying forcing |
| Latent reduction | None (ACDM); the transformer baselines use a latent space |
| Prediction target | Next state sample (probabilistic) |
| Rollout & stability | The paper's main subject. Very long rollouts in the appendix; stability criteria for unrolled training |
| Demonstrated scale | 2D grids (~128x64 range), 1000+ step rollouts |
| Datasets / physics | Wake flow, transonic cylinder, isotropic turbulence |
| Code + license | tum-pbs/autoreg-pde-diffusion — LICENSE_TBD |
| Integration effort | Medium — the diffusion wrapper is backbone-agnostic but inference is 20–100x slower |

## Relevance to FlameBench
**Protocol reference for the stabilisation ablation.** Its conclusions: (i) **latent-space transformers are accurate and stable when the state compresses easily** — encouraging for our POD/AE-transformers on a laminar forced flame; (ii) next-step predictors need unrolling or training noise on hard cases; (iii) training noise is the best cost/benefit stabiliser; (iv) diffusion ≈ unrolled training in accuracy, but expensive at inference. Suggests a FlameBench table with rows = stabilisation {none, noise, pushforward, unroll} x a few backbones. ACDM itself is optional (only if we want UQ/posterior samples).
