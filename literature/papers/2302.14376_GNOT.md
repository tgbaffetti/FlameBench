# GNOT: A General Neural Operator Transformer for Operator Learning (2023)

- **Authors / venue:** Z. Hao, Z. Wang, H. Su, C. Ying, Y. Dong, S. Liu, Z. Cheng, J. Song, J. Zhu (Tsinghua). ICML 2023.
- **Links:** https://arxiv.org/abs/2302.14376 · code https://github.com/thu-ml/GNOT
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators

## Summary
A linear-attention transformer operator for irregular meshes with **multiple heterogeneous inputs**. Each input (functions on their own meshes, boundary shapes, or *global parameter vectors*) is embedded by its own MLP. Query points attend to all input embeddings through a "heterogeneous normalized cross-attention", followed by self-attention. A **geometric gating** mixture-of-experts on the query coordinates acts as a soft domain decomposition for multi-scale problems.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Native irregular mesh / point cloud |
| Exogenous conditioning | **Natively supported**: a parameter vector theta in R^p is its own input with its own MLP encoder. `[phi history, phi(t+1)]` can be passed as theta without changing the architecture |
| Latent reduction | None (point tokens, linear attention) |
| Prediction target | Absolute field |
| Rollout & stability | Only the NS2d "predict last frames from first frames" task; no rollout study |
| Demonstrated scale | 2D/3D meshes up to O(10^4) points (NACA, Elasticity, NS2d-c, Inductor2d, Heat, Heatsink 3D) |
| Datasets / physics | Darcy, NS2d, NACA (Euler), Elasticity, steady NS with cavities, Maxwell inductor, multi-scale heat, heatsink multiphysics |
| Code + license | thu-ml/GNOT — LICENSE_TBD |
| Integration effort | **Low-medium.** Inputs = previous snapshots as a function on the mesh + phi as a parameter vector; queries = cell centres |

## Relevance to FlameBench
Good secondary transformer baseline, mainly because its multi-input design takes a scalar forcing vector as a first-class input. In REALM it degraded faster than FFNO/CNext on shocks and thin reaction zones, and Transolver reports beating it. Include it if we want two transformer operators; otherwise Transolver + UPT cover this family.
