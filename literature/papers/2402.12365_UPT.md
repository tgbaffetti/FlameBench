# Universal Physics Transformers: A Framework for Efficiently Scaling Neural Operators (2024)

- **Authors / venue:** B. Alkin, A. Fürst, S. Schmid, L. Gruber, M. Holzleitner, J. Brandstetter (JKU Linz / Emmi AI). NeurIPS 2024.
- **Links:** https://arxiv.org/abs/2402.12365 · project https://ml-jku.github.io/UPT · code https://github.com/ml-jku/UPT
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators (also 1: latent dynamics)

## Summary
An encoder–approximator–decoder transformer that works on any mesh or particle set. The **encoder** does message passing from mesh points to n_s randomly sampled "supernodes" (e.g. 2048), then transformer layers, then Perceiver pooling to a fixed n_latent tokens (e.g. 512). The **approximator** is a transformer that steps the latent state forward in time. The **decoder** is a Perceiver cross-attention queried at arbitrary coordinates. Two extra losses ("inverse encoding / decoding") make the pieces separable, so rollouts stay entirely in latent space ("latent rollout") and the mesh is never re-encoded.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | **Native unstructured mesh** or particles. Radius-graph message passing to supernodes; the random choice of supernodes preserves mesh density (implicit importance sampling) |
| Exogenous conditioning | **Built in:** DiT-style feature modulation (scale/shift/gate) of every transformer/perceiver block, driven by an embedding of the timestep and boundary conditions (they use inflow velocity, a scalar). Feeding `phi(t+1)` (and a phi-history embedding) through this path is a direct match to FlameBench's contract |
| Latent reduction | Learned fixed-size token latent (n_latent x h), trained end to end — a nonlinear, mesh-agnostic analogue of our POD latent |
| Prediction target | Next latent state; decoded field |
| Rollout & stability | Latent rollout. The paper explicitly uses **no** stabilisation tricks. Metric: number of steps until rollout Pearson correlation drops below 0.8 |
| Demonstrated scale | Transient pipe-flow CFD (OpenFOAM pisoFoam): 10k trajectories x 100 steps, **29k-59k mesh cells** (adaptive), 1-4 obstacles, variable inflow. Our 21k cells are in range |
| Datasets / physics | Transient NS on unstructured meshes, ShapeNet-Car (steady), Lagrangian SPH, regular-grid NS/shallow water |
| Code + license | ml-jku/UPT — LICENSE_TBD |
| Integration effort | **Medium.** Needs radius graph + supernode sampling (torch_geometric/torch_cluster) and the three-loss training. Maps well onto a `compute_loss` with latent next-step loss + reconstruction losses, like our `ae-transformer` |

## Relevance to FlameBench
**Priority candidate.** It is architecturally the "grown-up" version of our `ae-transformer` (a learned latent + transformer propagator), but mesh-native and with a principled conditioning path for a scalar forcing. Caveat: training cost in the paper is large (68M model ~450 A100-h on 8k trajectories). A small UPT (~8M) at our data size is realistic. Their baselines on the same task were GINO, and U-Net/FNO after interpolation to a grid, conditioned with FiLM / "spatial-spectral" conditioning. That is a template for how to condition our `fno3d`/`unet` on phi as well.
