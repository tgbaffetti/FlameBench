# Learning Control-Affine Reduced-Order Models via Autoencoders (2026)

- **Authors / venue:** A. Mjalled, M. Mönnigmann (Ruhr-Universität Bochum). arXiv preprint, Jun 2026.
- **Links:** https://arxiv.org/abs/2606.05045 · code+data https://github.com/mjalled/DeepE2EROM
- **Source read:** tex (arXiv e-print)
- **Thread:** 1 ROM + sequence / 5 conditioning

## Summary
An autoencoder ROM, trained end to end, whose latent dynamics are **control-affine**: `z_{k+1} = a(z_k) + B(z_k) · u_k` (drift net + state-dependent input matrix net). Inputs can themselves be encoded when high-dimensional. A **sequence-based extension** feeds a history of latents and inputs (extended state ξ_k) while keeping the affine structure. The structure enables feedback linearisation for control. Compared with a baseline AE with *linear* latent dynamics (Koopman-with-inputs style).

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Vector/grid states (1D heat equation, 64x64 camera frames) |
| Exogenous conditioning | **Structural: affine in the input**, `B(z)·u`. With u = phi, this is an interpretable, physics-motivated way to inject the forcing (the flame's response to phi depends on its current state through B(z)) |
| Latent reduction | Autoencoder (joint training) |
| Prediction target | Next latent (optionally sequence-conditioned) |
| Rollout & stability | Multi-step prediction evaluated on test trajectories |
| Demonstrated scale | Small (1D PDE, 64x64 images) |
| Datasets / physics | 1D heat equation with boundary control; boxed ball with force inputs |

| Integration effort | **Low** — a variant of `ae-transformer`/Koopman AE where phi enters as `B(z)·phi(t+1)` |

## Relevance to FlameBench
Provides a **principled conditioning variant** to compare against "concatenate phi to the input". FlameBench could run an ablation over the *form* of the phi injection (concatenate / FiLM / control-affine `B(z)·phi` / linear `B·phi`) on the same backbone. Small-scale validation only; treat it as a design idea, not a baseline to reproduce.
