# Message Passing Neural PDE Solvers — MP-PDE (2022)

- **Authors / venue:** J. Brandstetter, D. Worrall, M. Welling (Univ. Amsterdam / Qualcomm). ICLR 2022.
- **Links:** https://arxiv.org/abs/2202.03376 · code https://github.com/brandstetter-johannes/MP-Neural-PDE-Solvers
- **Source read:** tex (arXiv e-print)
- **Thread:** 3 GNNs + 6 rollout stability

## Summary
A fully neural message-passing solver that contains finite differences, finite volumes and WENO as special cases. It introduces two now-standard AR-training tricks. (1) **Pushforward trick:** unroll 2 steps, backprop only through the last one, so the model trains on its own predicted-input distribution ("zero-stability as domain adaptation"). (2) **Temporal bundling:** predict K future steps at once, cutting the number of solver calls (and distribution shifts) by K.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Regular or irregular grids as graphs (1D/2D) |
| Exogenous conditioning | **Built in:** an "equation embedding" theta_PDE (PDE coefficients, BCs) is concatenated into the encoder, **every edge message and every node update**. phi(t+1) and the phi history slot in directly as theta |
| Latent reduction | None |
| Prediction target | K future steps via a 1D-CNN decoder over time, **as residuals from the last known state** |
| Rollout & stability | Pushforward + temporal bundling; survival-time analysis; shows both tricks also help FNO |
| Demonstrated scale | 1D (n_x 50-100) and small 2D |
| Datasets / physics | Burgers/KdV families with varying coefficients, irregular grids, Dirichlet/Neumann BCs, 2D smoke |

## Relevance to FlameBench
Primarily a **training-protocol reference to apply to all AR models**. Our `compute_loss` is pure teacher-forced one-step. Adding a pushforward option (roll 1 extra step with no_grad, then compute the loss on the next) is a small change to `train.py` and makes the comparison fairer, since REALM also uses it. The explicit "parameter embedding everywhere" design also argues for injecting phi at every layer, not just the input, in all our models.
