# UP-dROM: Uncertainty-Aware and Parametrised dynamic Reduced-Order Model, application to unsteady flows (2025)

- **Authors / venue:** I. Zighed, N. Thome, P. Gallinari, T. Sayadi (Sorbonne Université / ISIR / CNAM). arXiv preprint, Mar 2025 (v3 May 2025).
- **Links:** https://arxiv.org/abs/2503.23236
- **Source read:** tex (arXiv e-print)
- **Thread:** 1 ROM + sequence / 5 conditioning & UQ

## Summary
A **VAE** compresses snapshots. A **transformer** over a time-delay window of latents (motivated by Takens embedding) predicts the future latents over a horizon h. The VAE and transformer are **trained jointly**. Parametrisation: an external variable ξ (e.g. Reynolds number, across a bifurcation) enters the transformer through **cross-attention**. UQ: VAE sampling gives confidence intervals in space, time and parameter space. That confidence is used for **adaptive sampling** of new training parameters.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Grid snapshots (cylinder wake; KS in the appendix) |
| Exogenous conditioning | **Cross-attention to external parameters ξ** — a static regime parameter in the paper, but cross-attention to a *sequence* of phi values is a natural extension for time-varying forcing |
| Latent reduction | VAE |
| Prediction target | Future latents over horizon h from lookback q |
| Rollout & stability | Horizon loss (multi-step), with uncertainty growth tracked over time |
| Demonstrated scale | 2D cylinder flow, multiple Re, including across the Hopf bifurcation (~Re 47) |
| Datasets / physics | Flow around a cylinder (Re 50-90+), Kuramoto–Sivashinsky |
| Code + license | Not stated |
| Integration effort | **Low** — this is our `ae-transformer` + KL term + cross-attention conditioning |

## Relevance to FlameBench
Nearly the same architecture as our `ae-transformer`, so it's a **reference implementation choice** rather than a new family. Two ideas worth adopting: (1) **cross-attention conditioning** as another phi-injection variant (see the Control-Affine card for the ablation idea); (2) VAE-based **uncertainty bands** — for a forced flame near a thermo-acoustic regime change, calibrated uncertainty is a strong selling point.
