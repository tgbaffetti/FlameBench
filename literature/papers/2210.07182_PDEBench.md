# PDEBench: An Extensive Benchmark for Scientific Machine Learning (2022)

- **Authors / venue:** M. Takamoto, T. Praditia, R. Leiteritz, D. MacKinlay, F. Alesiani, D. Pflüger, M. Niepert (NEC Labs Europe / Univ. Stuttgart / CSIRO). NeurIPS 2022 Datasets & Benchmarks.
- **Links:** https://arxiv.org/abs/2210.07182 · code https://github.com/pdebench/PDEBench · data on DaRUS (DOI; **CC BY**)
- **Source read:** tex (arXiv e-print)
- **Thread:** 4 benchmarks / 6 evaluation

## Summary
A benchmark suite of time-dependent PDEs (1D advection, Burgers, diffusion-reaction, diffusion-sorption; 2D Darcy, shallow water, diffusion-reaction; 1D/2D/3D compressible NS; inhomogeneous incompressible NS) with many ICs/BCs/parameters. It ships baselines (FNO, U-Net, PINN, a gradient-based inverse method) and an API. Its **metric set** was the first to go well beyond RMSE.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Regular grids only |
| Exogenous conditioning | PDE parameters vary across the dataset; baselines are trained per parameter (no conditioning mechanism) |
| Latent reduction | — |
| Prediction target | Next state (autoregressive or teacher-forced training modes for U-Net/FNO) |
| Rollout & stability | Temporal error analysis over the rollout |
| Demonstrated scale | 1D to 3D grids, many trajectories per PDE (see paper tables) |
| Datasets / physics | See above |
| Code + license | Code under a permissive open-source license (per the paper); data CC BY |
| Integration effort | N/A — **metrics and protocol reference** |

## Relevance to FlameBench
Borrow the **metric set**: RMSE, **nRMSE**, max error, **cRMSE** (error of a conserved/integral quantity — e.g. total heat release or total mass for a flame), **bRMSE** (error at boundaries — inlet/walls, relevant to our forced inlet), and **fRMSE** split into low/mid/high frequency bands. Also borrow the "data sheet" appendix format for documenting the FlameBench dataset (Datasheets for Datasets), which NeurIPS D&B reviewers expect.
