# Efficient Learning of Mesh-Based Physical Simulation with Bi-Stride Multi-Scale Graph Neural Network — BSMS-GNN (2022)

- **Authors / venue:** Y. Cao, M. Chai, M. Li, C. Jiang (UCLA / Snap / Google). ICML 2023.
- **Links:** https://arxiv.org/abs/2210.02573 · code https://github.com/Eydcao/BSMS-GNN
- **Source read:** tex (arXiv e-print)
- **Thread:** 3 GNNs

## Summary
A U-Net-shaped multi-scale GNN. The coarse levels are built as **preprocessing** by "bi-stride" pooling: keep every other BFS frontier of the mesh graph, then add 2-hop edges. This avoids hand-drawn coarse meshes and the wrong cross-boundary edges of proximity-based pooling. It uses one message-passing step per level, with non-parametric pooling/unpooling by interpolation. The multi-scale graph gets long-range information across the domain in few layers, fighting the over-smoothing / receptive-field problem of flat MGN.

## Relevance to FlameBench
Our mesh is **fixed**, so the multi-scale hierarchy is computed once — the ideal case for BSMS. It addresses exactly the failure mode REALM attributes to flat GNNs (over-smoothing, poor long-range coupling on large anisotropic meshes). Include it as the **multi-scale GNN** representative next to MGN, to test whether hierarchy fixes the GNN weakness on combustion meshes.
