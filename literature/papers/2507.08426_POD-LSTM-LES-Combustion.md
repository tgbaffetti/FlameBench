# Generative artificial intelligence and hybrid models to accelerate LES in reactive flows: Application to hydrogen/methane combustion (2025)

- **Authors / venue:** X. Zou, R. Abadía-Heredia, L. Saavedra, A. Parente, R. Xue, S. Le Clainche (Xi'an Jiaotong / UPM / ULB). arXiv preprint, Jul 2025.
- **Links:** https://arxiv.org/abs/2507.08426 · implementation to be released in ModelFLOWs-app (https://modelflows.github.io/modelflowsapp/)
- **Source read:** pdf (arXiv provides no LaTeX source; text extracted with pdftotext)
- **Thread:** 1 ROM + sequence / 4 combustion

## Summary
LES (EDC combustion model, 17-species / 58-step skeletal H2/CH4 mechanism, 1.96M-cell hexahedral mesh) of a jet-in-hot-coflow (JHC) burner, validated against experiments. A non-intrusive **POD-DL** hybrid forecasts the combustion field: POD (≥30 modes needed) per variable, then an **LSTM (2 layers x 100) + 2-layer MLP (200, ReLU) → next-step POD coefficients from the previous q=10 snapshots**, MSE loss, Adam, batch 12. Data: 500 snapshots at Δt=2e-4 s (first 250 train, last 250 test) and a coarser 200-snapshot set at 1e-3 s. Evaluated by contours, radial profiles, histograms and RRMSE over the rollout. Speed-up vs LES: 121x and 845x.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Any mesh (POD on snapshot vectors; structured hexahedral LES mesh here) |
| Exogenous conditioning | **None** — autonomous (statistically stationary) turbulent flame |
| Latent reduction | POD, per variable (T, Y_OH, Y_CO, Y_H2O, …), predicted in parallel |
| Prediction target | Next POD coefficients (absolute) |
| Rollout & stability | Autoregressive over the test half; error grows due to chaotic small scales; no stabilisation trick |
| Demonstrated scale | 1.96M cells, several species/temperature fields, ~250 training snapshots |
| Datasets / physics | Turbulent H2/CH4 JHC flame (LES) |

## Relevance to FlameBench
**Direct combustion precedent for our `lstm` baseline**, with the same design choices (POD, LSTM, 10-snapshot window). Good to cite as the "state of practice" in combustion ROM forecasting, and a reason to keep the POD+LSTM baseline. Differences to highlight: they predict **per-variable POD** (separate bases per field) with no forcing input, and use a temporal extrapolation split (first half train / second half test). FlameBench could run **per-field POD vs joint POD over all 11 fields** as a cheap ablation.
