# Benchmarking neural surrogates on realistic spatiotemporal multiphysics flows — REALM (2025)

- **Authors / venue:** R. Mao, R. Zhang, ..., H. Sun, Z. X. Chen (Peking Univ., Renmin Univ., AISI, Calgary, FM Global). arXiv preprint, Dec 2025 (v2 Feb 2026).
- **Links:** https://arxiv.org/abs/2512.18595 · code+data https://github.com/deepflame-ai/REALM · leaderboard https://realm-bench.org
- **Source read:** tex (arXiv e-print)
- **Thread:** 4 combustion/benchmarks (also 6 evaluation)

## Summary
REALM is the closest existing benchmark to FlameBench: 11 high-fidelity **reacting-flow** datasets (ignition in HIT, jet flame, detonations, scramjet cavity flame, rocket coaxial injectors, pool/facade fires) on 2D/3D, regular and **irregular** meshes, with one shared training/evaluation protocol. It benchmarks ~15 surrogates from five families (spectral, convolutional, transformer, pointwise, graph) at three capacity tiers (~1e6, 1e7, 1e8 params).

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Both. Spectral/CNN models only on regular cases; on irregular meshes: LSM, Transolver, DeepONet, PointNet, GraphSAGE, GraphUNet, MeshGraphNet |
| Exogenous conditioning | Static operating condition `C` per trajectory (equivalence ratio, Re, heat release, ...). **No time-varying forcing signal** — FlameBench's phi(t) is a real difference |
| Latent reduction | None (all models on native mesh) |
| Prediction target | Next state `U_{h+1} = G(U_h; dt, C)`; DeepONet used in time-conditioned (non-AR) form |
| Rollout & stability | Short-horizon AR unroll, **backprop only through the final step** (pushforward-like); MSE per feature group (chem, T, rho, u, p); Adam + One-Cycle LR |
| Demonstrated scale | 2e4 to 1.2e7 cells, 6 to 40 channels, 20-50 steps per trajectory, 6-36 trajectories per case. Irregular 2D cases: 2.9e5 to 3e6 cells |
| Datasets / physics | Reactive compressible NS with stiff chemistry (H2, CH4); DNS/LES |
| Code + license | GitHub deepflame-ai/REALM (license not stated in the paper; check repo) |
| Integration effort | N/A as a model; **high value as a protocol reference** and as a source of ready-made baseline implementations |

## Relevance to FlameBench
- **Must-cite positioning paper.** FlameBench's difference: single forced flame with a **time-varying scalar input phi(t)** and long trajectories (sine sweeps), vs. REALM's static-condition, short (20-50 step) trajectories.
- **Key finding for our irregular-mesh case:** on irregular meshes the pointwise **DeepONet had the lowest error**, and graph models (MGN, GraphSAGE) over-smoothed and were unstable. Spectral/CNN models won on regular grids (FFNO best, then CNext). This argues for including DeepONet + Transolver + one GNN in FlameBench rather than fixing FNO/UNet with interpolation only.
- **Reusable protocol pieces:** Box-Cox transform (lambda=0.1) on species mass fractions before z-scoring (relevant if our 11 fields include species/heat release); per-feature-group MSE; capacity tiers for fair comparison; metrics = relative L2 rollout curves, correlation, SSIM, inference throughput, plus physics diagnostics (integral quantities, cell size) because "high correlation != physically trustworthy".
- Their model zoo (FNO, FFNO, CROP, DPOT, UNO, LSM, CNext, FactFormer, Transolver, ONO, GNOT, DeepONet, PointNet, GraphSAGE, GraphUNet, MGN) is a ready-made candidate list with code.
