# Towards Multi-spatiotemporal-scale Generalized PDE Modeling — PDEArena (2022)

- **Authors / venue:** J. K. Gupta, J. Brandstetter (Microsoft Research). TMLR 2023.
- **Links:** https://arxiv.org/abs/2209.15616 · code https://github.com/microsoft/pdearena
- **Source read:** tex (arXiv e-print)
- **Thread:** 4 benchmarks / 5 conditioning

## Summary
A systematic comparison of ResNets, dilated ResNets, FNO variants, U-Nets with modern CV improvements (U-Net_mod, U-FNets with Fourier blocks in the down path) and UNO on 2D shallow water and Navier–Stokes (vorticity-stream and velocity form, **with an external buoyancy force**). It shows that **one surrogate can generalise across PDE parameters and time-step sizes** when conditioned properly. The unified PyTorch framework later also hosts PDE-Refiner.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Regular grid |
| Exogenous conditioning | **The key contribution for us.** Scalar parameters (buoyancy **force strength** f, time window Δt) → sinusoidal embedding → 2-layer MLP → injected in **every block** by (a) "Addition" or (b) **AdaGN** (FiLM-style scale/shift after GroupNorm, U-Nets), or, for FNOs, (c) **"Spatial-Spectral"** conditioning: a `FreqLinear` that multiplies the embedding into the Fourier modes as well as adding it in the spatial domain |
| Latent reduction | None |
| Prediction target | Next state(s) |
| Rollout & stability | One-step and rollout errors reported; the later Refiner work lives in the same codebase |
| Demonstrated scale | 2D grids; NS conditioning set = 832 force values |
| Datasets / physics | Shallow water (SpeedyWeather.jl), incompressible NS with buoyancy (Φ-Flow) |
| Code + license | microsoft/pdearena — LICENSE_TBD |
| Integration effort | Low — the conditioning modules are self-contained and can be ported to our FNO/UNet classes |

## Relevance to FlameBench
**The reference for how to condition grid models on a scalar forcing.** Our `FNO3DModel` / `UNetModel` currently broadcast phi as raw constant input channels, which PDEArena's ablations show is weaker than per-block conditioning. Concrete action: replace the broadcast channels with sinusoidal-embedding + AdaGN (UNet) / Spatial-Spectral (FNO), and **carry this into GINO**. The mechanism is also used for FNO/GINO baselines in UPT. It is also a good source of strong modern U-Net baselines (U-Net_mod), which beat classic U-Nets in most settings.
