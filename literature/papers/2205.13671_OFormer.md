# Transformer for Partial Differential Equations' Operator Learning — OFormer (2022)

- **Authors / venue:** Z. Li, K. Meidani, A. Barati Farimani (CMU). TMLR 2023.
- **Links:** https://arxiv.org/abs/2205.13671 · code https://github.com/BaratiLab/OFormer
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators (also 1: latent propagator)

## Summary
An encoder–propagator–decoder operator. The encoder runs self-attention (linear, with rotary relative position embeddings) over input samples. Query points (random-Fourier-feature coordinates) cross-attend to it. For time-dependent problems a **point-wise recurrent MLP with a skip connection advances the latent in time**, so the encoder is called once and full unrolled training is cheap. A point-wise MLP decodes.

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Arbitrary sampling (grid or irregular mesh); queries at any coordinates |
| Exogenous conditioning | None; would need phi concatenated into the latent propagator input at each step (easy, since the propagator is an MLP) |
| Latent reduction | Per-query-point latent (not compressed in the number of points) |
| Prediction target | Latent residual step (skip connection), decoded to absolute |
| Rollout & stability | Latent recurrent rollout with full unrolled training |
| Demonstrated scale | 1D/2D standard benchmarks; irregular meshes: FEniCS Poisson (electro/magnetostatics) and the MeshGraphNets compressible-airfoil Euler dataset (O(5k) nodes), recast as a non-Markovian initial-value problem |
| Datasets / physics | Burgers, Darcy, NS (FNO data), Poisson on irregular meshes, airfoil Euler flow (SU2) |

## Relevance to FlameBench
Mostly **historical / methodological**. Transolver reports unstable training for OFormer on ~32k-point meshes (cross-attention over massive point sets), which is our size range. Its latent-recurrent propagator idea is better represented by UPT. Low priority as a model; cite in the related work.
