# Deep learning for universal linear embeddings of nonlinear dynamics — Koopman autoencoder (2017)

- **Authors / venue:** B. Lusch, J. N. Kutz, S. L. Brunton (Univ. Washington). Nature Communications 9, 4950 (2018).
- **Links:** https://arxiv.org/abs/1712.09707 · code https://github.com/BethanyL/DeepKoopman (TensorFlow)
- **Source read:** tex (arXiv e-print)
- **Thread:** 1 ROM + sequence

## Summary
An autoencoder whose latent coordinates are Koopman eigenfunctions, so the latent dynamics are **linear**: `y_{k+1} = K y_k`. Three losses: reconstruction, linear latent prediction over m steps, and future-state prediction through the decoder. For continuous spectra, an auxiliary network makes the eigenvalues (frequencies/damping) depend on the latent state. Demonstrated on a cylinder wake at Re=100 (on and off the attractor).

## Benchmark fields
| Field | Value |
|---|---|
| Input geometry | Vector state (works on any mesh flattened, or on POD coefficients as in the paper's fluid example) |
| Exogenous conditioning | None in the paper. The standard controlled extension is `y_{k+1} = K y_k + B u_k` (Koopman with inputs / KIC); DMDc is its linear-latent analogue |
| Latent reduction | Nonlinear AE to Koopman coordinates |
| Prediction target | Latent via linear map K^m; multi-step losses |
| Rollout & stability | **Multi-step loss** (m steps) built into training; eigenvalue structure gives interpretable stability |
| Demonstrated scale | Toy systems + cylinder wake (low-dimensional after POD) |
| Datasets / physics | Discrete-spectrum toy, pendulum, cylinder flow |

| Integration effort | **Low.** Swap the transformer in `ae-transformer` for a linear K (+ B·phi): one extra model class |

## Relevance to FlameBench
A good **interpretable baseline between `pod-arx` (linear, POD) and `ae-transformer` (nonlinear, black box)**. A Koopman AE with a control input `B·phi` is a linear-in-latent forced oscillator. For a flame driven by a sine sweep, its eigenvalues can be read as the learned flame response modes / frequencies — a physically meaningful output for a combustion audience (link to flame transfer functions).
