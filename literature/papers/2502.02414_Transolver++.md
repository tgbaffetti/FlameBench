# Transolver++: An Accurate Neural Solver for PDEs on Million-Scale Geometries (2025)

- **Authors / venue:** H. Luo, H. Wu, H. Zhou, L. Xing, Y. Di, J. Wang, M. Long (Tsinghua). ICML 2025.
- **Links:** https://arxiv.org/abs/2502.02414 · code in the thuml/Transolver repository family (https://github.com/thuml/Transolver)
- **Source read:** tex (arXiv e-print)
- **Thread:** 2 neural operators

## Summary
An upgrade of Transolver with three changes. (1) Slice weights come from a Gumbel-softmax with a **per-point learned temperature** ("eidetic states"), which stops the slices collapsing into average pooling in deep models. (2) The redundant feature projection is removed, halving memory. (3) Multi-GPU parallelism communicates only the M slice tokens. It reaches 1.2M points on one GPU.

## Relevance to FlameBench
At 21k cells we don't need the scaling features. The **eidetic-state fix is the useful part**: it targets sharp local features, which is exactly where REALM saw Transolver over-smooth thin reaction zones. Include it as a Transolver ablation/variant (Transolver vs. Transolver++ slice weights) rather than as a separate model family.
